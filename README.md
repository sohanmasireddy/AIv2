# AIv2
LINK: https://abc123ai.streamlit.app/

Uses Streamlit Community Cloud

Uses Cloudflare Workers API

Uses Gemma 4, IBM Granite 4, and GPT-OSS. Has file uploads and voice recognition using OpenAI Whisper and image compressor and also has web search powered by DuckDuckGo.

Uses CSS SVG liquid glass UI. No WebGL or WebGPU used.

Only works on Chromium based browsers.
